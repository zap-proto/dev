# SDKs

ZAP ships first-class implementations for every major language. All implementations target byte-for-byte compatibility with the spec, share the same `.zap` schema language, and follow the same versioning.

## Core SDKs

| Language | Package | Repo | Status |
|---|---|---|---|
| TypeScript / JavaScript | `@zap-proto/zap` | [zap-proto/ts](https://github.com/zap-proto/ts) | stable |
| Go | `github.com/zap-proto/go` | [zap-proto/go](https://github.com/zap-proto/go) | stable |
| Python | `zap-proto` | [zap-proto/py](https://github.com/zap-proto/py) | stable |

## Protocols

ZAP is both a native RPC system and a carrier for higher-level protocols. See the [protocols section](/docs/protocols) for full guides.

| Protocol | Package | Repo | Guide |
|---|---|---|---|
| **Native ZAP RPC** | (any SDK) | — | [Native ZAP RPC](/docs/protocols/native) |
| HTTP (net/http drop-in) | `github.com/zap-proto/http` | [zap-proto/http](https://github.com/zap-proto/http) | [HTTP over ZAP](/docs/protocols/http) |
| MCP (Model Context Protocol) | `github.com/zap-proto/mcp` | [zap-proto/mcp](https://github.com/zap-proto/mcp) | [MCP over ZAP](/docs/protocols/mcp) |
| A2A (Agent-to-Agent) | `github.com/zap-proto/a2a` | [zap-proto/a2a](https://github.com/zap-proto/a2a) | [A2A over ZAP](/docs/protocols/a2a) |
| ACP (Agent Communication, FIPA-style) | `github.com/zap-proto/acp` | [zap-proto/acp](https://github.com/zap-proto/acp) | [ACP over ZAP](/docs/protocols/acp) |
| RNS (Resource Name Service) | `github.com/zap-proto/rns` | [zap-proto/rns](https://github.com/zap-proto/rns) | [RNS over ZAP](/docs/protocols/rns) |
| FIX 4.4 / 5.0 trading | `github.com/zap-proto/fix` | [zap-proto/fix](https://github.com/zap-proto/fix) | [FIX over ZAP](/docs/protocols/fix) |
| WS (multi-stream pubsub) | `github.com/zap-proto/ws` | [zap-proto/ws](https://github.com/zap-proto/ws) | [WS over ZAP](/docs/protocols/ws) |
| Bench (HTTP perf harness) | `github.com/zap-proto/bench` | [zap-proto/bench](https://github.com/zap-proto/bench) | [Benchmarks](/docs/benchmarks) |
